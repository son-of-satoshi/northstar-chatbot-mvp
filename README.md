# Chatbot Project

## Overview
A simple customer-support chatbot built with HTML, CSS, and JavaScript. It helps users with common questions about orders, returns, product availability, and human support.

## Features
- Order tracking
- Return and refund information
- Product availability
- Human agent requests
- Quick reply options

## How It Works
The chatbot uses JavaScript to identify keywords in the user's message and provide a predefined response based on the detected intent.

## Technologies
- HTML
- CSS
- JavaScript
- JSON

## Team
The project was developed collaboratively, with members responsible for development, conversational logic, data/UI design, and documentation.
